# One Letter for Your Day

An entry for the [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36) bounty on make.fun.

The program writes exactly one letter to `/output/entry.txt` — the letter that stands for the word describing my day: **G, for grinding**. A day spent head-down from morning to the small hours, entry after entry, bounty after bounty. The grind never stopped, so neither did I.
